# TEC_Proyecto_C_OO
## Battle Simulator!
Este proyecto esta hecho para poder aprender Programación Orientada a Objetos, utilizando diferentes cosas aprendidas en clase como: sobreescritura, sobrecarga, herencia, polimorfismo, clases abstractas, etc.

Se crean 3 diferentes tipos de personajes para pelear, cada uno haciendo cosas diferentes.
El mago tiene acceso a hechizos que hacen cada uno mas daño que el otro pero con mas chance de fallar
El asesino puede hacer daño critico, triplicando su daño
El caballero puede utilizar el poder del santo para hacer mas daño o curarse

Un simulador de batalla por turnos te dejara pelear hasta ganar o perder
¿Te crees capaz de hacer buenas elecciones y ganar contra los 3 enemigos?
Demuestralo y juega ahora, selecciona tu clase y pelea, teniendo varias opciones que podrian hacer mas daño por mas chance de fallar, o menos daño pero mas seguro de conseguirlo.
Si ganas te daremos un pastel de tu eleccion!

## Funcionalidad
El simulador se queda en un loop hasta que todos los enemigos hayan sido derrotados y tu hayas sido derrotado
Las diferentes clases solo te dejaran elegir tu nombre y titulo, los valores de vida y fuerza ya estan predeterminados
Dependiendo de tus opciones puestas en diferentes menus, te dejara atacar de manera distinta
El bot elige las opciones para atacarte dependiendo de los valores conseguidos por un randomizador
Al matar a todos los enemigos, el jugador gana y termina la simulacion
Igual termina la simulacion si tu mueres
